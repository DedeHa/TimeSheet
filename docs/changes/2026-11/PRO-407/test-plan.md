## Defects found and fixed

| Defect | Found by | Fix |
|--------|----------|-----|
| `resume --force` printed "resumed successfully" but left the pipeline reported as interrupted | `test_resume_with_force_clears_interruption` | `pipeline.py` `resume()` sets status to `resumed` when clearing an interruption |
| `test_agent_team_system.py` wrote to the real `~/.opencode/pipeline-state.json` | mtime of the real state file changed during the agent suite | Autouse fixture redirects `detect_mode.STATE_PATH` to `tmp_path`. The session-level guard (V16) now covers the whole suite. |
| Read-only commands created a state entry and a history entry for an unknown ticket | `test_pipeline_read_only.py`: 17 of 20 cases failed against the pre-change `pipeline.py` | Read paths use `_peek_entry`, which does not persist (FR-22) |
| The CLI never set the status, so `in_progress` was never produced | Code review (architect finding 4) and `test_pipeline_status.py` | The CLI sets `in_progress` on advance and `blocked` on BLOCKED |
| `continue` could advance with no handoff and no DoR record | Architect findings 5 and 6 | Handoff gate (V10) and DoR gate (V11) in `continue` |
| The naming check rejected pytest's `conftest.py` after the isolation guard was added | `test_ci_tests_use_test_prefix` in the app suite | The check allows `conftest.py` by name (commit `5299a29`) |
| `continue --force` bypassed the DoR gate; the test pinned the bypass | Architect finding 1 (blocker) | DoR gate separate from the handoff rule (V18, commit `644e5f6`) |
| A corrupt state or history file loaded as empty; read commands showed a fresh plan | Architect finding 3, tester finding 7 | Fail closed (V19, commit `e242d06`) |
| A BLOCKED pipeline was cleared by an IN_PROGRESS handoff; `show state` disagreed with the flag | Architect finding 4 | IN_PROGRESS does not clear a block; forced continue clears it with a reason (V20, commit `482b7cd`) |
| Every new step counted as interrupted (in_progress with zero cycles); a fresh `continue` showed the banner and blocked `resume` | Tester finding 3, architect finding 5 | One clock-based rule, `interruption_reason()` (V21, commit `fa1e044`). A completed step awaiting `continue` is also not interrupted. |
| Handoff steps were not checked against the pipeline step | Architect finding 6 | `--step` must equal the current step (V22, commit `6c950a0`). The agent docs use the pipeline steps. |
| `continue " PRO-5 "` created a separate entry; `PRO-`/`GH-` were accepted as generic references | Architect finding 7, tester finding 6, architect minor | One normaliser for every command, malformed tracker keys rejected (V23, commit `7088106`) |
| `waive D1` was accepted; the D3 pass condition made the template DoD fail | Architect finding 8 | D1 not waivable; D3 narrowed (V24, commit `e2fefd9`) |
| Refusals exited 0; `set-mode` with an invalid mode wrote a state entry first | Tester finding 1 | Exit code contract 0/1/2, documented in AGENTS.md (V25, commit `a277ebc`) |
| The latest-handoff rule was untested with a completed cycle | Tester finding 2 | Isolated tests and mutation check (V26, commit `a1ab42f`) |
| `--base` went to git unchecked; blank `--changed` entries were counted; the save used a fixed temp name without fsync; read commands could create the home directory | Architect minor findings 9, 8 and 14; tester finding 4 | V27, commits `036aecc`, `8871002`, `b676fee`, `6614e1b` |
